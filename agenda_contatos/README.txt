AGENDA DE CONTATOS - PHP + MySQL + XAMPP

1. Instale/inicie Apache e MySQL no XAMPP.
2. Copie a pasta agenda_contatos para C:\xampp\htdocs\
3. Abra http://localhost/phpmyadmin
4. Importe o arquivo database.sql.
5. Abra http://localhost/agenda_contatos/

Banco: agenda_contatos
Usuário padrão XAMPP: root
Senha padrão: vazia

Funcionalidades:
- Criar contato
- Listar contatos
- Pesquisar
- Editar
- Excluir
- Foto/avatar
- Nome, telefone, e-mail e endereço
- Layout responsivo
